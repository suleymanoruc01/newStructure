## UI Wiring İz Sürme Diyagramı

```mermaid
sequenceDiagram
  actor Tester as WhatsApp Tester
  participant Screen as Ekran / Görünüm
  participant Handler as Handler / Callback
  participant State as State / ViewModel / Store
  participant Rule as Validasyon / İş Kuralı
  participant Service as Service / Repository / Native Bridge
  participant Result as Görünür Sonuç / Karşı Aktör
  Tester->>Screen: Vaka görevi ve kullanıcı aksiyonu
  Screen->>Handler: onClick / onPress / route event
  Handler->>State: state veya intent güncellemesi
  State->>Rule: validasyon, guard, branching
  Rule->>Service: API, persistence, native veya backend-boundary yan etkisi
  Service-->>State: başarı, hata veya senkronizasyon sonucu
  State-->>Result: ekran durumu, navigasyon, liste yenileme, bildirim veya karşı aktör görünümü
```
